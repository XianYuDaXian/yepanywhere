# Codex Web 界面与会话能力改动记录

Date: 2026-05-16

## 概要

这几轮修改主要围绕 Codex 在 yepanywhere Web 端的可用性、会话展示、移动端布局和信息可见性展开。

目标是让 Web 端更接近 Codex App 的操作方式。

## 主要改动

1. 新建会话入口补齐。
- 新建会话时支持普通对话和选定文件夹两种工作区入口。
- 普通对话默认进入 `Documents/Codex/当天日期` 目录。
- 选定文件夹直接使用当前项目目录作为工作区。

2. Codex 的模型与思考强度支持补齐。
- 新建会话页增加独立的模型按钮。
- 新建会话页增加独立的思考强度按钮。
- 会话内的模型切换和思考强度切换改为 Codex 专用样式。
- 思考强度改成下拉菜单。
- 模型切换改成下拉菜单。
- slash 菜单也补齐为和 Codex CLI 更接近的入口。

3. slash 行为补齐。
- `/model`、`/compact`、`/init`、`/plan`、`/status`、`/skill` 已纳入前端可见命令。
- slash 菜单改成更适合 Web 的弹出样式。
- `/compact` 触发了上下文压缩流程。
- `/skill` 连接了 Codex 的技能选择。

4. 会话信息与限额展示调整。
- 顶部的限额提示移入会话信息。
- 用户点击会话信息后再查看限额。
- 会话信息里补了 Codex 的 5 小时窗口和周窗口。
- 限额时间做了秒和毫秒两种来源的兼容。
- 移动端支持点按查看上下文长度。

5. 会话列表与项目列表分离。
- 左侧栏把项目会话和普通对话分开显示。
- 项目会话和普通对话分别按最近条数展示。
- 继续展开的方式保留在列表里。

6. 会话输入区的桌面与移动端布局重做。
- 桌面端把输入区收进独立卡片。
- 用户消息保持右侧气泡样式。
- 工具栏按钮做了统一的高度和圆角。
- 模型按钮和思考强度按钮的样式对齐。
- 移动端把附件按钮、斜杠按钮、发送按钮和设置区重新排布。
- 移动端 slash 按钮调整到更靠近附件按钮的位置。
- 移动端的横向溢出做了裁切。

7. 计划模式和权限模式拆分。
- 计划模式从权限模式里拆出来。
- 计划模式不再直接代表默认权限。
- 权限模式和自动编辑模式的文案做了同步。

8. 进程信息面板扩展。
- 会话信息弹层补了 Codex 的限额信息。
- 进程信息继续保留上下文、模型、来源、沙箱等内容。

9. 术语与文案统一。
- 多语言文案补了 Codex 的思考强度、模型、限额和技能相关字段。
- 旧的 Claude 语境文案开始向 Codex 语境收敛。

## 结果

Web 端已经可以更完整地呈现 Codex 会话的常用操作。

当前重点已经从“能不能用”转向“像不像 Codex App”。

## 验证

前端类型检查已通过。

已多次使用浏览器对桌面端和移动端做过目视核对。
